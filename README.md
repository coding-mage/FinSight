# FinSight

FinSight is a full-stack financial literacy web application designed to help users build healthy money habits through personalized insights and interactive simulation. Developed as a project for the Hackonomics hackathon.

## Features

- **Personalized Insights**: Track expenditures and receive custom advice to optimize savings and budgeting.
- **Interactive Simulation**: Run financial scenarios (such as loan interest rates, investment growth, and compounding) to visualize long-term outcomes.
- **Habit Tracker**: Track weekly and monthly budgets to reinforce positive financial routines.

## Project Structure

The project is structured as a decoupled frontend and backend repository:

- `finance-buddy-app-frontend/`: User interface and interactive dashboards.
- `finance-buddy-app-backend/`: API services, database integrations, and simulation engines.
